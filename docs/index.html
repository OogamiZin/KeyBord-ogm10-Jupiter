Vial 対応ファームのキーボードに WebHID で接続し、マクロ（M0〜）を編集します。ファームの書き換えは不要です。

マクロはテキストで書きます。文章やコードはそのまま貼り付けられ、キー操作は {LCTL+C} のように波かっこで書きます。

キーボードが手元にない場合は「デモで試す」で画面と変換の動きを確認できます。

    プレビューは実際に送られる順番です。黄色がキー操作、緑が待機、枠付きは押したままの操作です。

    書き方動作
    そのままの文字その文字を入力します（半角英数字と記号のみ）。タブは Tab になります。
    エディタ内の改行見た目を整えるだけで、送られません。Enter を送るには {ENTER} と書きます。
    {ENTER} {F5}キーを1回押します。KC_ を付けた名前も使えます。
    {LCTL+C} {LCTL+LSFT+K}修飾キーとの組み合わせを押します。
    {TAB*3}同じ操作を繰り返します。
    {+LSFT} … {-LSFT}キーを押したままにし、あとで離します。
    {WAIT:200}200ミリ秒待ちます（最大 65024）。
    {0x7C16}キーコードを16進数で直接指定します。
    {{ }}波かっこ自体を文字として入力します。

    修飾キー名: LCTL LSFT LALT LGUI / RCTL RSFT RALT RGUI（CTRL SHIFT ALT GUI CMD WIN も可）。記号キーの文字は OS のキーボード配列設定で決まります。日本語などの全角文字はマクロでは送れません。

    レイヤーをテキストで編集・貼り付け

    表示中のレイヤー全体を文字で編集できます。別のレイヤーの内容や、keymap.c の [0] = LAYOUT( … ) をそのまま貼り付けて「レイヤーに反映」を押してください。キーの並びは行・列の順です。

    レイヤー -

    キーの左上の青い文字は、Shift を押しながら打つと出る文字です（JIS 配列）。薄い表示は、下のレイヤーの割り当てがそのまま効いているキーです。丸いキーはエンコーダーの回転（↺ 反時計回り、↻ 時計回り）です。

    クリックしたキーを Ctrl・Shift などを先にクリックすると、次のキーとの組み合わせになります。

    キーボードのロックを解除

    マクロの書き込みにはロック解除が必要です。解除用のキーを、バーが満タンになるまで押し続けてください。

    中止する場合はケーブルを抜き差ししてください。
