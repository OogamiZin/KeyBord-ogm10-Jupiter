# 設定ツール（マクロ編集・キー割り当て・レイヤー表示）

[← トップページに戻る](../README.md)

ブラウザだけで動く、ogm10-Jupiter 用の設定ツールです。Vial 対応ファームウェアのキーボードに WebHID でつなぎ、マクロとキー割り当てを編集します。ファームウェアの書き換えなしで、変更はすぐキーボードに保存されます。

**https://oogamizin.github.io/KeyBord-ogm10-Jupiter/**

## 使い方

1. パソコンの Chrome か Edge で https://oogamizin.github.io/KeyBord-ogm10-Jupiter/ を開きます（Safari と Firefox は WebHID に対応していないため使えません）。
2. 「キーボードに接続」を押し、一覧から ogm10-Jupiter を選びます。
3. 上部のボタンで「マクロ編集」「キー割り当て」「レイヤー表示」を切り替えます。

キーボードが手元にないときは「デモで試す」で画面の動きを確認できます。

ネットにつながらない場所で使うときは、[`index.html`](index.html) をダウンロードして、そのファイルを Chrome か Edge で開いてください。1 ファイルだけで動きます。

## できること

### マクロ編集

- 文章やコードをそのまま貼り付けられます。キー操作は `{LCTL+C}` のように波かっこで書きます。
- エディタ内の改行は見た目だけで、送られません。Enter は `{ENTER}` と書きます（複数行を貼ると自動で付きます）。
- `{TAB*3}`（繰り返し）、`{+LSFT}…{-LSFT}`（押したまま）、`{WAIT:200}`（待機）が使えます。
- 画面下の仮想キーボードをクリックするか、「キー入力を取り込む」で実際に押して入力できます。
- 書き込みにはロック解除（Q と P の位置のキーを同時に長押し）が必要です。

### キー割り当て

- 盤面でキーを選び、文字で入力するか、仮想キーボード・キー入力の取り込み・選択式で割り当てます。
- 文字は `LCTL+LSFT+K`、`LT(2,LBRC)`、`MO(1)`、`M0` のように書きます。QMK の書き方（`LCTL(KC_C)`、`(QK_LGUI|KC_L)`、`_______`）もそのまま貼れます。
- 「レイヤーをテキストで編集・貼り付け」で、レイヤー全体をまとめて編集できます。`keymap.c` の `[0] = LAYOUT( … )` や、Vial の保存ファイル（.vil）からの取り込みにも対応しています。
- 変更は「キーボードに書き込む」を押すまで反映されません。書き込み後に読み戻して照合します。

### レイヤー表示

- 今有効なレイヤーのキー割り当てを、基板の配置どおりに表示します。レイヤーを切り替えると表示も追従します。
- レイヤーの用途（0〜2: Windows、3〜5: Mac、6: マクロ、7: ユーザー）を、色分けした枠と名前で表示します。キー割り当ての画面でも同じ表示です。
- キーの左上の青い文字は、Shift を押しながら打つと出る文字です（JIS 配列）。
- 専用キー（LyrStat など）とマクロの説明を、盤面の下に凡例として出します。説明文は `vial.json` の `title` から読みます。
- 「小窓で表示」で、他のアプリの上に浮かせておけます。

レイヤーへの追従には、レイヤー状態を通知するファームウェアが必要です（[ファームウェアの説明](../qmk_firmware/keyboards/ogm10_jupiter/readme.md#レイヤー状態の通知表示ツール向け)）。古いファームウェアでは、レイヤー番号をクリックして手動で切り替えます。

## このフォルダについて

`docs/` の中身が、そのまま GitHub Pages で公開されます（main ブランチの `/docs` を公開元に設定）。`index.html` を更新して main に入れると、数分で公開ページにも反映されます。

## 制約

- タップダンス、コンボ、キーオーバーライドの編集には対応していません。標準の Vial を使ってください。
- 全角文字はマクロで送れません。
- 標準の Vial と同時に開くと、通信が混ざることがあります。片方ずつ使ってください。
