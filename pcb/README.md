## 注文するもの

| 何を | どこで | 使うデータ |
|---|---|---|
| メイン基板（部品実装込み） | JLCPCB（PCB + PCBA） | `pcb/ogm10-Jupiter-pcb.json` から出力した **Gerber（zip）・BOM（csv）・CPL（csv）** の 3 つ |
| トッププレート・ボトムプレート | JLCPCB（PCB のみ） | [plate/README.md](../plate/README.md) を見てください |
| 手はんだ部品（ソケット 43 個・エンコーダー 2 個） | LCSC、AliExpress など | [手はんだする部品](#自分ではんだ付けする部品) の表 |

リポジトリにあるのは EasyEDA のソース（JSON）だけで、Gerber・BOM・CPL は入っていません。次の手順で自分で出力します。

| ファイル | 内容 |
|---|---|
| `ogm10-Jupiter-pcb.json` | 基板データ。**ここから Gerber・BOM・CPL を出力します** |
| `ogm10-Jupiter-schematic.json` | 回路図。注文には使いません（回路の確認用） |

## 1. EasyEDA で注文用ファイルを出力する

1. [EasyEDA Standard](https://easyeda.com/editor) を開きます（Pro 版ではなく Standard 版です。ログインが必要です）。
2. 「ファイル > 開く > EasyEDA ソース」（File > Open > EasyEDA Source）で `ogm10-Jupiter-pcb.json` を開きます。
3. 次の 3 つを出力します。

| 出力するもの | メニュー（英語表示） | できるファイル |
|---|---|---|
| Gerber | 製造 > PCB 製造ファイル（Gerber）<br>（Fabrication > PCB Fabrication File (Gerber)） | `Gerber_….zip` |
| BOM（部品表） | 製造 > BOM（Fabrication > BOM） | `BOM_….csv` |
| CPL（部品座標） | 製造 > ピック＆プレース ファイル（Fabrication > Pick and Place File） | `PickAndPlace_….csv` |

- Gerber の出力時に DRC の確認が出たら、そのまま進めて構いません。
- Gerber の画面にある「JLCPCB で注文」（Order at JLCPCB）を押すと、Gerber が JLCPCB の注文画面に直接送られます。その場合も BOM と CPL は上の手順で出力しておき、PCBA の画面でアップロードします。

## 2. JLCPCB に注文する

[JLCPCB](https://jlcpcb.com/) の注文画面で Gerber の zip をアップロードし、次のように設定します。書いていない項目は初期値のままで構いません。

### 基板の設定

| 項目 | 設定 | 備考 |
|---|---|---|
| Base Material | FR-4 | |
| Layers | 2 | |
| Dimensions | 229.2 × 76.2 mm | Gerber から自動で入ります |
| PCB Qty | 5 | 最小数 |
| PCB Thickness | **1.6 mm** | バンパーケースは 1.6 mm の基板に合わせて作っています |
| PCB Color | 好きな色 | 色によっては料金・日数が変わります |
| Surface Finish | HASL / LeadFree HASL / ENIG のどれでも | |

### 部品実装（PCBA）の設定

| 項目 | 設定 | 備考 |
|---|---|---|
| PCB Assembly | ON | |
| PCBA Type | Standard | USB-C の固定脚と JP1 がスルーホール部品のため |
| Assembly Side | **Bottom Side** | 実装部品はすべて裏面です |
| PCBA Qty | 2〜5 | 実装してもらう枚数 |
| Confirm Parts Placement | **Yes** | 製造前にエンジニアが部品の向きを確認してくれます |

次の画面で BOM と CPL の csv をアップロードし、部品の割り当てを確認します。

- 各部品の LCSC 番号が [JLCPCB が実装する部品](#jlcpcb-が実装する部品すべて裏面) の表と一致しているか確認します。在庫がない部品は、同じ定格・パッケージの部品に差し替えます。
- **ホットスワップソケット（SW3–SW45）とロータリーエンコーダー（ENC1, ENC2）は選択を外して（実装しない）ください。** 届いてから手はんだします。
- R4 は現在のデータでは削除済みです。BOM に R4 が出てきたら古いデータなので、選択を外してください（[理由](#usb-ハブ)）。

## 3. 部品の向きを確認・修正する

EasyEDA から出力した CPL のままだと、JLCPCB 側で一部の部品の向きがずれます。BOM の次の部品配置の画面（3D ビューアー）で、必ず確認・修正してください。

### ビューアーの見方

- 部品はボトム面に実装するため、JLC のビューアーではボトム面が**左右反転**して表示されます（EasyEDA の画面と左右が逆になります）。
- マゼンタの点が **1番ピン**、ダイオードの「−」が**カソード**です。
- 基板のシルク（黒い点やダイオード記号）と重ねて照合すると分かりやすいです。

### 修正が必要な部品

| Ref | 部品 | 修正 | 正しい状態（JLC ビューアー上） |
|---|---|---|---|
| USBC1–USBC4 | TYPE-C-31-M-12 | 向きが逆 → 反転 | マゼンタの点（ピン）が基板の内側、差し込み口が基板の外側を向く |
| U1 | CH334F | 180° 回転 | 1番ピンの点が左下 |
| U2 | RP2040 | 回転 | 1番ピンの点が右下（シルクの黒点と一致） |
| U3 | W25Q128 | 回転 | 1番ピンの点が右下のピン（シルクの点と一致） |
| U4 | XC6206 | 180° 回転 | 2ピン側が右、1番ピン（GND）が右下。EasyEDA 上では GND パッドが左下・+3V3 が左上 |
| D13 | 1N4148W | 180° 回転 | 「−」が左。EasyEDA 上では右側のパッド（ROW0 側）がカソード |

### 修正不要な部品（確認済み）

| Ref | 確認内容 |
|---|---|
| D1（USBLC6） | 1番ピンの点が左下でシルクと一致 |
| D2 | 「−」が左（EasyEDA 上で右側パッド＝ROW0 側がカソード） |
| D3–D46（縦向き） | 「+」が上、「−」が下 |
| X1, X2（水晶） | 180° ずれても電気的に問題なし（90° ずれは NG） |
| 抵抗・コンデンサ | 極性なし |

### 注文前後のチェックリスト

- [ ] PCB Thickness 1.6 mm、Assembly Side は Bottom Side になっている。
- [ ] 「Confirm Parts Placement」を Yes にした。
- [ ] SW3–SW45 と ENC1 / ENC2 を実装しない設定にした。R4 が BOM に入っていない。
- [ ] 上の表の部品を一つずつ、EasyEDA の PCB 画面と見比べて確認した（左右反転に注意）。
- [ ] 注文後 4〜6 時間ほどで、Order History の DFM Analysis を確認する。

## 4. 届いたら手はんだする

### 自分ではんだ付けする部品

JLCPCB の PCBA では実装しないので、別に買って手はんだします。

| Ref | Part | 付ける面 | LCSC | Qty |
|---|---|---|---|---|
| SW3–SW45 | Choc ホットスワップソケット CPG135001S30 | 裏面（JLC の実装部品と同じ面） | C5333465 | 43（予備を含めて 45〜50 個あると安心） |
| ENC1, ENC2 | ロータリーエンコーダー EC11 / EC12（どちらも使用可、プッシュスイッチ付き）<br>例: ALPS EC11E18244A5（18パルス / 36クリック） | 表面から差し込み、裏面ではんだ付け | C255515（EC11E18244A5） | 2 |

- ソケットは裏面のシルク（フットプリント）に合わせて置き、2 つのパッドをはんだ付けします。
- エンコーダーはスイッチと同じ表面側から差し込みます。ノブの軸の D カットの長さは [knob/README.md](../knob/README.md) で確認してください。
- 初回（2026年11月）の製造分は R4（ハブ PSELF の 10kΩ プルダウン）が実装されています。付いたままだと Mac で「アクセサリに電力が必要です」と表示されて RP2040 が認識されないので、取り外してください（[理由](#usb-ハブ)）。

はんだ付けが終わったら、ボトムプレートを付ける前にファームウェアを書き込みます（BOOT 用の JP1 がボトムプレートで隠れるため）。手順は [トップページの「作り方」](../README.md#作り方) を見てください。

## USB ハブ

- 上流の USB-C IN から CH334F（4ポートハブ）に入り、ポート1〜3 を USB-C OUT1〜3、ポート4 を RP2040 に接続しています。
- 入力は ESD 保護（USBLC6-2SC6）と 2A ポリスイッチを通り、出力側の 5V ラインには 22µF ×4 のバルクコンデンサ、各出力ポートの CC には 56kΩ プルアップ（Rp）が付いています。
- 5V 系の配線は周囲とのクリアランスが取れる範囲で最大 1mm まで太くしています（狭い箇所は 0.3〜0.5mm）。
- 出力ポートの合計電流は、上流のポートが供給できる範囲（一般的なPCのポートなら 500mA〜900mA 程度）に収まるように使ってください。
- CH334F の PSELF ピンは未接続（R4 なし）で、ハブはセルフパワーとして申告します。プルダウン（R4）を付けるとバスパワー申告になり、RP2040 のブートローダーなど 100mA を超える電流を申告するデバイスがホストに拒否されます。
